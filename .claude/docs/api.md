# API

Краткий обзор эндпоинтов. Точные схемы тел запросов/ответов — в Swagger UI
(`pnpm dev`, затем `http://localhost:4000/api/docs`) или прямо в
`packages/shared/src/schemas/*.ts` (DTO в `apps/api/src/modules/*/dto/` — это те же схемы,
обёрнутые `createZodDto`).

## Общее

- Базовый путь: `/api/v1` (`app.setGlobalPrefix('api/v1')` в `main.ts`).
- Авторизация: `Authorization: Bearer <access-токен>`. Безопасность закрыта по умолчанию —
  каждый эндпоинт требует токен, кроме помеченных **Public** ниже.
- Refresh-токен передаётся не в заголовке, а в httpOnly cookie — выставляется и читается
  сервером автоматически при вызовах `/auth/*`.
- Rate limiting: глобально 100 запросов/мин на IP; `/auth/register`, `/auth/login`,
  `/auth/refresh` ограничены отдельно и строже (см. `auth.controller.ts`).
- Формат ошибок — единый, `apiErrorSchema` из `packages/shared` (создаёт `AllExceptionsFilter`):
  код статуса, сообщение, при 400 от Zod — разбор по полям. Детали 5xx в ответ не попадают,
  только в лог.

## Auth — `/auth` (все эндпоинты Public)

| Метод | Путь             | Описание                                          |
| ----- | ---------------- | ------------------------------------------------- |
| POST  | `/auth/register` | Регистрация нового пользователя                   |
| POST  | `/auth/login`    | Вход по email и паролю                            |
| POST  | `/auth/refresh`  | Обновить пару токенов по refresh-cookie (ротация) |
| POST  | `/auth/logout`   | Выйти и отозвать refresh-токен                    |

## Users — `/users`

| Метод | Путь        | Описание                      |
| ----- | ----------- | ----------------------------- |
| GET   | `/users/me` | Профиль текущего пользователя |

## Categories — `/categories`

| Метод  | Путь              | Описание                      |
| ------ | ----------------- | ----------------------------- |
| GET    | `/categories`     | Список категорий пользователя |
| POST   | `/categories`     | Создать категорию             |
| PATCH  | `/categories/:id` | Изменить категорию            |
| DELETE | `/categories/:id` | Удалить категорию             |

## Transactions — `/transactions`

| Метод  | Путь                    | Описание                                                             |
| ------ | ----------------------- | -------------------------------------------------------------------- |
| GET    | `/transactions`         | Лента транзакций: фильтры (дата/тип/категория) + курсорная пагинация |
| GET    | `/transactions/summary` | Сводка за месяц: доходы, расходы, баланс, разбивка по категориям     |
| GET    | `/transactions/:id`     | Одна транзакция                                                      |
| POST   | `/transactions`         | Создать транзакцию                                                   |
| PATCH  | `/transactions/:id`     | Изменить транзакцию                                                  |
| DELETE | `/transactions/:id`     | Удалить транзакцию                                                   |

`/transactions/summary` объявлен в коде раньше `/transactions/:id` намеренно: Nest сопоставляет
маршруты в порядке объявления.

## Budgets — `/budgets`

| Метод  | Путь                | Описание                                                                |
| ------ | ------------------- | ----------------------------------------------------------------------- |
| GET    | `/budgets`          | Бюджеты пользователя                                                    |
| GET    | `/budgets/progress` | Бюджеты вместе с фактическими тратами за текущий период                 |
| POST   | `/budgets`          | ⚠️ Заглушка — `BudgetsService.create` бросает `Error('Не реализовано')` |
| PATCH  | `/budgets/:id`      | ⚠️ Заглушка — `BudgetsService.update` бросает `Error('Не реализовано')` |
| DELETE | `/budgets/:id`      | ⚠️ Заглушка — `BudgetsService.remove` бросает `Error('Не реализовано')` |

## Health — `/health` (Public)

| Метод | Путь      | Описание                                             |
| ----- | --------- | ---------------------------------------------------- |
| GET   | `/health` | Статус сервиса и доступность БД (`SELECT 1`), uptime |

Используется оркестратором/балансировщиком — поэтому без токена.
